D · One hint pattern (built on this branch)

InfoHint is the single way to explain something: it opens on mouse hover, on keyboard focus and on tap, pins on click, closes on Escape or an outside tap, and describes its button while open. Tooltip only names icon buttons and no longer sticks after a tap.

Explanation in running text before
Single-key shortcuts
One-key shortcuts in the Quran reader: / to search, S for the sidebar, P, H, E, T and 1-4 for the annotation tools. Turn them off if you use speech input or press keys by accident.
